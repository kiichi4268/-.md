# 🤝 協賛提案書テンプレート（Macachette Sports）

スポーツブランド・飲料・プロテイン・ジム・地域の飲食店などに、イベント協賛を提案するための書式です。
📈 マーケターAI（`prompts/sponsor_proposal.md`）がこの章立てで下書きを作ります。`【要編集】` は実数に置き換えてください。

> **数値の出どころ**: 参加者数・初参加率・一人参加率は `data/events.csv`、年代や関心は開催後アンケート（LINE）の集計。
> 個人を特定できる情報は提案書に載せず、人数と割合だけを使います。

---

## 1. 表紙
- 件名：「Macachette Sports × 【ブランド名】 協賛のご提案」
- 提出日・提出者・連絡先

## 2. 私たちについて（3行）
- 東京（新宿・代々木・目黒・中野など）で、社会人向けのスポーツ交流イベントを月【要編集】回開催
- 種目：バドミントン、バレーボール、フットサル、卓球ほか
- 特徴：参加者の約8割が一人参加、初心者歓迎、用具レンタルあり

## 3. 参加者データ（直近3か月）
| 指標 | 数値 |
|---|---|
| 月間参加者数（延べ） | 【要編集】名 |
| 年代 | 20代【要編集】% / 30代【要編集】% |
| 初参加率 | 【要編集】% |
| 一人参加率 | 【要編集】% |
| 公式LINE 友だち数 | 【要編集】名 |
| Instagram フォロワー数 / 月間リーチ | 【要編集】 / 【要編集】 |

**ブランド視点でのポイント**（例）
- 「これから運動を習慣にしたい」20〜30代に、**運動直後のタイミング**で接触できる
- 一人参加が多いため、イベント後の SNS 投稿・口コミが個人単位で広がりやすい

## 4. 協賛メニュー（小さく始められる3段階）
| プラン | 内容 | 協賛金の目安 |
|---|---|---|
| ライト（サンプリング） | イベント1回で商品を参加者全員に配布／試飲。開催レポ投稿で商品を紹介（PR表記あり） | 【要編集】円〜 または商品提供のみ |
| スタンダード（月間） | 月の全イベントでサンプリング＋告知画像・LINE参加証へのロゴ掲出＋SNS投稿2本 | 【要編集】円／月 |
| 冠イベント | 「【ブランド名】Presents ◯◯会」を開催。企画・告知・当日運営・レポートまで | 【要編集】円／回 |

> 価格の考え方：まずは「商品提供＋小額」で実績を作り、レポートの数値を持って月間プランへ移行する。

## 5. 実施後のレポート（協賛側に渡すもの）
- 配布数・試飲数、当日の写真（掲載許可済み）
- SNS 投稿のリーチ・保存数・プロフィールアクセス数
- 参加者アンケート（商品の印象・購入意向）の集計

## 6. 表記・ルール
- SNS・ブログでの紹介には「PR」「提供：【ブランド名】」を明記します（ステルスマーケティング規制への対応）
- 参加者の写真は掲載許可を得たものだけを使います
- 健康効果などの表現は、ブランドから提供された表現の範囲に限ります

## 7. スケジュール
| 時期 | 内容 |
|---|---|
| 【要編集】 | 打ち合わせ・プラン決定 |
| 【要編集】 | 告知開始（開催14日前〜） |
| 【要編集】 | イベント開催 |
| 開催1週間後 | 実施レポート提出 |

## 📋 提案先リスト（優先順の目安）
| 優先 | 業種 | 接点の作り方 |
|---|---|---|
| 1 | 地域の飲食店・BAR（系列店を含む） | 打ち上げ・クーポン連携から。最も話が早い |
| 2 | プロテイン・スポーツ飲料（D2Cブランド） | 公式サイトの「サンプリング・協賛」問い合わせ窓口 |
| 3 | スポーツウェア・シューズ（中小ブランド・セレクトショップ） | 店舗スタッフ経由・Instagram DM |
| 4 | ジム・整体・ストレッチ専門店 | 体験チケットの配布（成果報酬型も提案可） |

## 開催後アンケートに入れておく設問（協賛データ用）
- 年代（20代前半／20代後半／30代前半／30代後半／40代〜）
- 運動頻度（週1以上／月1〜3／ほぼしない）
- 興味のあるもの（ウェア・シューズ／プロテイン・栄養／ジム／ケア用品）
