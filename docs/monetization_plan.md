# 💴 月20万円 収益化プラン（4本柱のKPI分解）

現状の月3〜5万円（集客約30名）から、**月20万円以上の固定収益**にするための数値計画です。
📊 アナリストAI の週次レポート（`weekly_review` チェーン）はこの表を基準に進捗を判定します。

> 下の数値の多くは**仮置き**です（★印）。実績が出たら書き換えてください。

---

## 1. 目標の内訳

| 柱 | 月の目標 | 主なKPI | 立ち上がりの速さ |
|---|---|---|---|
| ① イベント参加費（利益） | 10万〜12万円 | 月間参加者数・大型枠の充足率 | 速い（1〜2か月） |
| ② ハイブリッド有料note | 3万〜5万円 | 販売部数 | 中（2〜3か月） |
| ③ WordPress（Sports Backstage） | 2万〜3万円 | 月間PV・クリック率 | 遅い（6〜12か月） |
| ④ スポンサー・協賛 | 2万〜3万円 | 契約社数 | 中（実績1〜2回の後） |
| **合計** | **17万〜23万円** | | |

**優先順位**：①が全体の半分以上を占め、②④の材料（実績・参加者データ）も①から生まれるため、**最初の3か月は①に時間の7割を使う**。③は記事を積み上げるだけの低負荷運用にする。

## 2. 柱① イベント参加費：必要な参加者数

```
月の利益 = Σ（参加費 × 参加人数 − 会場費 − 用具・雑費）
1人あたり利益 = 参加費 − (会場費 + 雑費) ÷ 参加人数
```

| 前提（★仮置き） | 値 |
|---|---|
| 参加費 | 1,500円 |
| 会場費（3時間・公共体育館） | 1回 8,000円 ★ |
| 雑費（シャトル・ボール等） | 1回 2,000円 ★ |

| 1回の参加人数 | 1回の利益 | 1人あたり利益 |
|---|---|---|
| 12名 | 8,000円 | 約670円 |
| 20名 | 20,000円 | 1,000円 |
| 30名 | 35,000円 | 約1,170円 |
| 40名 | 50,000円 | 1,250円 |

→ **月10万〜12万円には「30名規模の回を月3〜4回」か「40名規模の回を月2〜3回」**が必要（月90〜110名）。
人数が少ない回ほど1人あたりの利益が下がるため、**大型枠の充足率を上げることが最も効く**。

### 打ち手（担当）
- 充足率に応じた枠埋め投稿（`prompts/fill_capacity_template.md`）… 🎬 ディレクター／✍ ライター
- LINE で申込20秒・参加証即発行（`docs/autosns_setup_guide.md`）… 📈 マーケター
- リピート率の向上（開催後の次回案内）… 📈 マーケター
- 価格の見直し（大型枠のみ1,800円などのテスト）… 🤝 相談役が判断材料を整理

### 週次KPI
| KPI | 目標 |
|---|---|
| 大型枠（定員20名以上）の開催3日前の充足率 | 70%以上 |
| 月間参加者数 | 90名以上 |
| リピート率（2回目以降の参加者の割合） | 40%以上 ★ |
| SNS → LINE 友だち追加数 | 週15名以上 ★ |

## 3. 柱② ハイブリッド有料note

```
月の売上（手取り） = 価格 × 販売部数 − note の手数料（料率は note 公式で確認）
```

| 価格 | 月3万円に必要な部数（手数料差引前） | 月5万円 |
|---|---|---|
| 500円 | 60部 | 100部 |
| 980円 | 31部 | 52部 |

- **月2本のペースで積み上げ**、過去記事が売れ続ける状態を作る（6本で月30部 = 1本あたり月5部が目安）
- 生成: `python scripts/generate_content.py --chain note_hybrid --theme "..."`
- 告知: 無料部分の要約を Threads・X で、イベント告知と同じ週に流す

### ネタ帳（初期6本）
1. 一人参加で浮かない社会人スポーツイベントの選び方（参加者向け）
2. 体育以来の運動でも恥をかかない、当日の立ち回りと持ち物（参加者向け）
3. 30代からバドミントンを始めて続けるコツ（参加者向け）
4. 社会人サークル・単発イベント・スクールの違いと選び方（参加者向け）
5. 都内の公共体育館を確保する手順（団体登録・抽選・キャンセル拾い）（主催者向け）
6. SNS→LINE→参加証まで自動化した集客の仕組み（主催者向け）

## 4. 柱③ WordPress（Sports Backstage）

```
月の収益 = 月間PV × アフィリエイトのクリック率 × 成約率 × 平均報酬
```

| 前提（★仮置き） | 値 |
|---|---|
| クリック率 | 3% ★ |
| 成約率 | 3% ★ |
| 平均報酬 | 400円 ★ |

→ 1PV あたり約0.36円 ★。**月2万円には約5.5万PV**が必要になり、柱の中で最も時間がかかる。
そのため、記事は「アフィリエイト収益」と同時に「イベント集客（LINE登録）」の入口として評価する。

- **月4本**（施設ガイド2本・ノウハウ/比較2本）を目安に積み上げる
- 生成: `python scripts/generate_wordpress_post.py --theme "..."` → AIの出力を保存 → `--finalize` で仕上げ
- アフィリエイトリンクは `data/affiliate_links.yml` に登録（未登録のままでは公開前チェックで止まる）
- WordPress.com のプランによって、使える機能（プラグイン・広告など）が異なるため、運用前に確認する
