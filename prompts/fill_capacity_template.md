# 🎯 枠埋めテンプレート（不安払拭型 SNS投稿）

大型枠（定員20〜40名）や申込の少ない会場の集客ムラをなくすためのテンプレートです。
ディレクターAIが `data/events.csv` の数値を見て **パターン A / B / C** を選び、ライター・デザイナー・動画制作AIがこのテンプレートに沿って成果物を作ります。

- チェーン: `prompts/agents.yml` の `fill_capacity`
- 元データ: `data/events.csv`（列と計算式は `data/README.md`）
- **数値・参加者の声は元データにあるものだけを使う。創作は品質管理AIが差し戻す**

---

## 1. 差し込み変数

| 変数 | 内容 |
|---|---|
| `{{date}}` `{{weekday}}` `{{start}}` `{{end}}` | 日付・曜日・時間 |
| `{{sport}}` `{{area}}` `{{venue}}` `{{fee}}` | 種目・地域・会場・参加費 |
| `{{capacity_max}}` `{{applied}}` `{{remaining}}` `{{fill_rate}}` | 定員・申込数・残り枠・充足率 |
| `{{first_timer_pct}}` `{{solo_pct}}` | 申込者の初参加率・一人参加率（申込5名未満なら使わない） |
| `{{voices}}` | 参加者の声（掲載許可済みのもののみ） |
| `{{days_left}}` | 開催日までの日数 |
| `{{past_solo_pct}}` | これまでのイベント全体の一人参加率（既定: 80%。実績が変わったら更新） |

---

## 2. パターンの選び方（判定表）

大型枠で「残り32枠」と出すと「人気がない」と受け取られます。**充足率が低いうちは残り枠を出さず、安心材料と参加者の顔ぶれで勝負する**のが原則です。

| 状況 | パターン | 主役にする情報 | 出さない情報 |
|---|---|---|---|
| 申込5名未満、または充足率30%未満 | **A：安心訴求** | これまでの実績（`{{past_solo_pct}}` が一人参加）、当日の流れ、初心者向けの配慮 | 現在の申込数・残り枠 |
| 充足率30〜70% | **B：顔ぶれ・参加者の声** | 現在の参加予定人数と構成（初参加◯割・一人参加◯%）、参加者の声 | 残り枠 |
| 残り枠が定員の30%以下、または残り5枠以下 | **C：残り枠カウントダウン** | 残り◯枠、締切、参加予定の構成 | — |

### 投稿タイミング（開催日からの逆算）
| 時期 | 推奨 | 媒体 |
|---|---|---|
| 14日前 | A または B のカルーセル | Instagram / Threads / X / note |
| 7日前 | B のリール（参加者の声・過去開催の映像） | Reels / Shorts / TikTok |
| 3日前 | B または C のストーリーズ＋Threads | Instagram ストーリーズ / Threads / X |
| 前日 | C のストーリーズ（残り枠があれば） | Instagram ストーリーズ / LINE |

---

## 3. パターンA：安心訴求（「一人で浮かない？」を払拭）

### 🎨 カルーセル（1080x1350・6枚）
| 枚 | メインコピー | サブコピー・要素 |
|---|---|---|
| 1 表紙 | 「一人で行って浮かない？」 | `{{date}}({{weekday}})` `{{area}}`で`{{sport}}`会 |
| 2 共感 | 体育以来、久しぶり。知り合いもいない。 | 「その不安、参加者のほとんどが最初に感じてました」 |
| 3 数値 | **これまでの参加者の`{{past_solo_pct}}`が一人参加** | 円グラフ1つだけ。数字を最大サイズで |
| 4 当日の流れ | 受付 → 自己紹介ゲーム → レベル別にゆるく → 休憩トーク | 時間割をアイコンで |
| 5 配慮 | 用具レンタル無料・上手い人に合わせない | 「ラリーが続かなくてOK」 |
| 6 CTA | プロフィールのリンクから30秒で予約 | 日時・会場・参加費・保存してね |

### 🎬 ショート動画台本（約20秒）
| 秒数 | 映像 | テロップ |
|---|---|---|
| 0-3秒 | 体育館の入口を一人で入ってくる後ろ姿 | 一人で行って浮かない…？ |
| 3-8秒 | 受付で笑顔で迎えられる | これまでの参加者の`{{past_solo_pct}}`が一人参加 |
| 8-14秒 | 初心者同士のゆるいラリー、失敗して笑う | 下手でも笑ってOKな空気です |
| 14-20秒 | 開催情報テキスト | `{{date}}({{weekday}})` `{{area}}` 詳細はプロフィールから |

### 🧵 Threads / 🐦 X（共通の骨子）
> 「一人で行って浮かないかな」って、申し込む前にみんな思うみたいです。実際これまで参加者の`{{past_solo_pct}}`は一人参加でした。`{{date}}({{weekday}})` `{{area}}`の`{{sport}}`会、体育以来の人もぜひ。詳細はプロフィールから。

### 📱 ストーリーズ
- 1枚目: アンケートスタンプ「一人参加って不安？ はい／ちょっと」← 反応した人に DM で案内できる
- 2枚目: 「参加者の`{{past_solo_pct}}`が一人参加」＋リンクスタンプ「予約はこちら」

## 4. パターンB：顔ぶれ・参加者の声（「どんな人が来る？」を払拭）

### 🎨 カルーセル（1080x1350・6枚）
| 枚 | メインコピー | サブコピー・要素 |
|---|---|---|
| 1 表紙 | 「今回の参加メンバー、こんな感じです」 | `{{date}}({{weekday}})` `{{area}}`で`{{sport}}`会 |
| 2 数値 | **現在`{{applied}}`名が参加予定** | 初参加`{{first_timer_pct}}`・一人参加`{{solo_pct}}` をアイコンで |
| 3 声① | `{{voices}}` の1つ目 | 属性（年代・初参加かどうか）を小さく |
| 4 声② | `{{voices}}` の2つ目 | 声が1つしか無い場合はこの枚を削除 |
| 5 当日の雰囲気 | 実写写真（掲載許可済み） | 「休憩中のおしゃべりが一番盛り上がります」 |
| 6 CTA | プロフィールのリンクから30秒で予約 | 日時・会場・参加費 |

### 🎬 ショート動画台本（約25秒）
| 秒数 | 映像 | テロップ |
|---|---|---|
| 0-3秒 | 参加者がコートに集まっている引き | 今回のメンバー、初参加が`{{first_timer_pct}}` |
| 3-10秒 | 参加者の声（テキストを画面に重ねる） | `{{voices}}` |
| 10-18秒 | ハイタッチ・笑顔のカット | 一人参加`{{solo_pct}}`。みんな最初は一人でした |
| 18-25秒 | 開催情報テキスト | `{{date}}({{weekday}})` 現在`{{applied}}`名参加予定 |

### 🧵 Threads / 🐦 X（共通の骨子）
> `{{date}}`の`{{sport}}`会、いま`{{applied}}`名が参加予定です。そのうち初参加が`{{first_timer_pct}}`、一人参加が`{{solo_pct}}`。前回の参加者さんからは「`{{voices}}`」という声をもらいました。詳細はプロフィールから。

## 5. パターンC：残り枠カウントダウン（「迷っているうちに締切」を後押し）

> 使えるのは残り枠が定員の30%以下、または残り5枠以下のときだけです。実際より少なく見せる表現は景品表示法上のリスクがあるため禁止。

### 🎨 カルーセル（1080x1350・4枚）
| 枚 | メインコピー | サブコピー・要素 |
|---|---|---|
| 1 表紙 | **残り`{{remaining}}`枠** | `{{date}}({{weekday}})` `{{area}}`の`{{sport}}`会 |
| 2 顔ぶれ | 初参加`{{first_timer_pct}}`・一人参加`{{solo_pct}}` | 「今からでも一人で大丈夫」 |
| 3 詳細 | 日時・会場・参加費・持ち物 | 用具レンタル無料 |
| 4 CTA | プロフィールのリンクから予約 | 締切（前日○時など、実際のルール） |

### 🎬 ショート動画台本（約15秒）
| 秒数 | 映像 | テロップ |
|---|---|---|
| 0-3秒 | 前回の集合写真（掲載許可済み） | `{{date}}`の`{{sport}}`会、残り`{{remaining}}`枠 |
| 3-10秒 | ゆるいラリー・笑顔 | 一人参加`{{solo_pct}}`・初参加`{{first_timer_pct}}` |
| 10-15秒 | 開催情報テキスト | 予約はプロフィールから |

### 📱 ストーリーズ
- カウントダウンスタンプ（開催日時）＋「残り`{{remaining}}`枠」＋リンクスタンプ
